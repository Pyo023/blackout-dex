# blackout-dex

Blackout Roguelike - Talent/Curse Compendium, hosted with GitHub Pages.

- Korean: https://pyo023.github.io/blackout-dex/
- English: https://pyo023.github.io/blackout-dex/?lang=en

## Files

- `index.html` - the compendium (single self-contained file, KO/EN toggle built in).
- `.nojekyll` - serve files as-is (no Jekyll processing).
- `404.html` - fallback page linking back to the compendium.

## Update

1. Regenerate `BlackOut-Index.html` in the workspace (rebuild + bilingual patch).
2. Run `deploy-gh-pages.ps1` (or double-click `deploy-gh-pages.bat`).
3. Changes go live in 1-2 minutes.
